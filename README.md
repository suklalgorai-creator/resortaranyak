## Production checklist

Before deploying, configure the values in `.env.example` in the hosting provider:

- `DATABASE_URL` pointing to the production PostgreSQL database
- `AUTH_SECRET` and `CRON_SECRET` as long random secrets
- `INITIAL_ADMIN_EMAIL` and `INITIAL_ADMIN_PASSWORD` only for the first seed
- `NEXT_PUBLIC_APP_URL` set to the deployed site URL

Run `npm run db:migrate` against the production database, then verify `GET /api/health` returns `status: "ok"` and `database: "connected"`. Public bookings use a request flow and do not require payment credentials right now.
